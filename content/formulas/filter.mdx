mistakes:
  - level: error
    title: Not available before Excel 2021
    body: FILTER returns #NAME? in Excel 2019 and earlier. It is a dynamic array function and there is no fallback that behaves the same way. For files that leave your organization, this is the deciding factor.
  - level: error
    title: The spill range is blocked
    body: FILTER needs empty cells below and to the right to place its results. Anything in the way gives #SPILL!. Clear the space rather than trying to make the formula smaller.
  - level: warning
    title: Nothing matches and no if_empty is set
    body: With no third argument, a filter matching nothing returns #CALC!. Always supply if_empty — an empty string or a short message — so a legitimate empty result does not look like a broken formula.
  - level: warning
    title: The condition must be the same height as the array
    body: Filtering A2:D7 with a condition built on B2:B8 gives #VALUE!. The condition produces one TRUE or FALSE per row and there has to be exactly one per row of the array.
faq:
  - q: How do I filter and total in one step?
    a: Wrap it. =SUM(FILTER(D2:D7, B2:B7="North")) hands the filtered rows straight to SUM. This is often clearer than SUMIFS once the condition gets complicated, because the condition reads as a condition rather than as alternating range and criteria arguments.
  - q: How do I filter on two conditions?
    a: Multiply them. FILTER(A2:D7,(B2:B7="North")*(C2:C7="Closed")) is AND. Add them with a plus sign for OR. Multiplication converts TRUE and FALSE to 1 and 0.
  - q: Can FILTER return only some columns?
    a: Yes, if you point the array at just those columns. To pick non-adjacent columns you would wrap it in CHOOSECOLS, or run two FILTER formulas side by side.
  - q: What is the difference between FILTER and an AutoFilter?
    a: AutoFilter hides rows in place and is a manual action. FILTER produces a new live range that updates automatically as the source data changes. For anything feeding a report, FILTER is the better tool.
  - q: What can I use in Excel 2019?
    a: There is no clean equivalent. AutoFilter for manual work, a PivotTable for summaries, or SUMIFS and COUNTIFS when you only need aggregates rather than the rows themselves.

## Examples

### 1. Filtering one column

<Formula>=FILTER(A2:A7, B2:B7="North")</Formula>

Try it in the grid above. Four orders come back, spilled one under another. In Excel you would normally point the first argument at the whole table — `=FILTER(A2:D7, B2:B7="North")` — and get all four columns of every matching row.

The condition is not a criteria string like SUMIFS wants. It is an ordinary comparison that produces TRUE or FALSE for each row, which is why it reads the way you would say it out loud.

### 2. Two conditions

`=FILTER(A2:D7, (B2:B7="North")*(C2:C7="Closed"))`

Multiplication is AND, because TRUE times TRUE is 1 and anything times FALSE is 0. Addition is OR. Note that each condition needs its own brackets — leave them out and the arithmetic binds in the wrong order.

<Callout type="tip" title="AND and OR in dynamic arrays">
Multiply for AND, add for OR. `(B2:B7="North")+(B2:B7="South")` returns rows from either region. It looks strange the first time — you are doing arithmetic on logic — but it is the standard idiom and worth recognising.
</Callout>

### 3. Handling an empty result

Always give FILTER a third argument:

`=FILTER(A2:D7, B2:B7="West", "No orders")`

Without it, a filter that matches nothing returns `#CALC!`, which looks like a mistake rather than a legitimate answer of "none".
