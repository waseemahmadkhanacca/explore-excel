mistakes:
  - level: error
    title: Forgetting the space between words
    body: '=CONCATENATE(B2, C2) produces SarahWhitfield. Separators are never added for you — every space, comma and dash has to be supplied as its own argument in quotes.'
  - level: warning
    title: It cannot take a range
    body: '=CONCATENATE(A2:A7) does not join a column. Older versions return only the value on the same row, and it is never what you wanted. TEXTJOIN is the function that accepts a range.'
  - level: warning
    title: Numbers lose their formatting
    body: Joining a cell displaying £1,200.00 gives 1200, because CONCATENATE takes the underlying value and not the format. Wrap it in TEXT with a format string to keep the appearance.
  - level: warning
    title: Dates come through as serial numbers
    body: A date joined into text becomes 46037 rather than 15 Jan 2026. Excel stores dates as numbers and CONCATENATE reads the number. Use TEXT with a date format to convert it first.
faq:
  - q: What is the difference between CONCATENATE, CONCAT and TEXTJOIN?
    a: CONCATENATE is the original and takes individual values. CONCAT replaced it and additionally accepts ranges. TEXTJOIN goes further by taking a delimiter once and applying it between every item, which is what you usually want.
  - q: Should I use the ampersand instead?
    a: For two or three values, yes — B2&" "&C2 is shorter and every version supports it. CONCATENATE reads more clearly once there are many parts, because the arguments line up.
  - q: Is CONCATENATE being removed from Excel?
    a: Microsoft describes it as available for backward compatibility and recommends CONCAT. It still works in current versions and there is no announced removal date, but new work should use CONCAT or TEXTJOIN.
  - q: How do I join a whole column?
    a: Use TEXTJOIN, which takes a range and a delimiter. CONCATENATE cannot do it, and trying produces a result that looks plausible on the first row and is wrong everywhere else.
  - q: How do I keep currency formatting when joining?
    a: Wrap the number in TEXT — TEXT(D2,"£#,##0.00") — before joining. Without it you get the raw stored value with no separators or symbol.

## Examples

### 1. Joining a name

The classic use, and the classic mistake is leaving out the middle argument.

<Formula>=CONCATENATE(B2, " ", C2)</Formula>

The `" "` is a literal space. Without it the two names run together. Every separator you want has to be written out.

### 2. Reversing the order

<Formula>=CONCATENATE(C2, ", ", B2)</Formula>

Surname first, for sorting. Note the separator here is a comma *and* a space, written as one string.

<Callout type="tip" title="The ampersand does the same job">
`=B2 & " " & C2` is identical in effect and shorter to type. Most people use the ampersand for short joins and CONCATENATE when there are enough parts that the arguments are easier to read than a chain of ampersands. Neither is more correct.
</Callout>

### 3. Building something from parts

<Formula>=CONCATENATE(LOWER(B2), ".", LOWER(LEFT(C2, 1)), "@example.com")</Formula>

Other functions nest inside freely. This lowercases the first name, takes the first letter of the surname, and assembles an address. Generating identifiers this way is far more reliable than typing them.
