mistakes:
  - level: error
    title: Not available before Excel 2021
    body: SORT returns #NAME? in Excel 2019 and earlier. There is no formula equivalent that behaves the same way — the Sort button is the fallback, with the difference that it changes the data rather than producing a live copy.
  - level: error
    title: The spill range is blocked
    body: SORT needs empty cells for its output. Anything in the way gives #SPILL!. Because the result is the same size as the source, this usually means clearing a block rather than a single cell.
  - level: warning
    title: sort_index counts from the array, not the sheet
    body: Sorting C2:F7 by column 2 sorts by column D, not column B. The index is relative to the range you passed in, which is the same trap INDEX sets.
  - level: warning
    title: Sorting a range that includes headers
    body: Include the header row in the array and it gets sorted along with the data, usually ending up somewhere in the middle. Start the array below the headers.
faq:
  - q: Can I sort a filtered list?
    a: Yes, and it is one of the most useful pairings. =SORT(FILTER(D2:D7, C2:C7="Closed"), 1, -1) filters to the closed orders and then ranks them largest first. Dynamic array functions nest freely, and the inner one runs first.
  - q: How do I sort by more than one column?
    a: Pass arrays for sort_index and sort_order — =SORT(A2:D7,{2,4},{1,-1}) sorts by column 2 ascending then column 4 descending. The braces make an array constant.
  - q: What is SORTBY?
    a: SORTBY sorts one range according to the values in another, including a column that is not part of the output. Use it when the sort key should not appear in the result.
  - q: Does SORT change my original data?
    a: No, and that is the main advantage. It produces a sorted copy elsewhere. The Sort button rearranges the data in place, which is irreversible once saved.
  - q: How do I get just the top five?
    a: Combine with TAKE in Excel 365 — =TAKE(SORT(A2:D7,4,-1),5). In Excel 2021 use LARGE with INDEX and MATCH, or sort and reference the first five rows.

## Examples

### 1. Ranking a column

<Formula>=SORT(D2:D7, 1, -1)</Formula>

Largest first. Drop the `-1` and you get smallest first, since ascending is the default. Try both in the grid above.

In a real sheet you would usually sort the whole table rather than one column — `=SORT(A2:D7, 4, -1)` orders every row by the fourth column, keeping each order number attached to its own amount.

### 2. Sorting a filtered list

<Formula>=SORT(FILTER(D2:D7, C2:C7="Closed"), 1, -1)</Formula>

The inner FILTER runs first and hands its results to SORT. This pairing — narrow it down, then rank it — covers a large share of what people build PivotTables for.

### 3. When you only want the single biggest

<Formula>=INDEX(A2:A7, MATCH(MAX(D2:D7), D2:D7, 0))</Formula>

This answers "which one is biggest" rather than "how big is the biggest", and it works in every version of Excel. Reach for it when you need one answer in one cell and a spilled list would be in the way.

<Callout type="tip" title="Sorting without touching the data">
The real advantage of SORT is that it leaves the source alone. On a shared workbook, using the Sort button rearranges rows for everyone, permanently, and there is no record of what the order used to be. A SORT formula in a separate area gives you the view you need without that risk.
</Callout>
